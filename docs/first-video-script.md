# First Video — "The Call" launch edit (script + shot list)

**Length:** 18–22s · **Format:** 1:1 for X feed (also export 9:16) · **Tool:** whatever you settle on (motion.so trial) — the spec below is tool-agnostic.

**Grammar (borrowed from the Hyperliquid edit):** dark chrome, film grain, heavy vignette, glowing mint (#8ff5dc) serif-italic captions landing one word at a time, one hard logo hit at the end. **Ours, not theirs:** no borrowed interview footage, no lyric quotes, cleared audio only (a commercial track like the Drake reference risks a mute/strike on X — accept knowingly or use cleared trending audio).

## Copy rules for this and every video
- Captions are original. Never quote a song.
- No numbers that could read as projections (no APY, no "10x", no win-rates).
- The only claims: what the mechanism does, and that it's public.
- End card carries the site URL, never a contract address (CAs go only in pinned thread + site, at launch minute).

## Variants to cut from the same assets
1. **Pre-call teaser (6s):** clock counting down to the real NVDA date, caption *the machine is listening.*
2. **Post-call, win (8s):** lock tx hash → locked-supply counter ticking up → *it bought. it locked. it never sells.*
3. **Post-call, loss (8s):** red candle → pool counter ticking down → *it bled. next call.* (post this one with the same production value — receipts culture only works if losses look as good as wins)
